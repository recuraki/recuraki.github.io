## ドライバのインストール(出来なかった)
(なにもいらないらしい)
`Broadcom NetXtreme-E Niccli Utility - Linux`をいれる。
```shell
unzip niccli-227.0.130.0_linux.zip
cd Linux/Linux_x86_64/
sudo dpkg -i *deb
cd ../..
cd Linux/sliff
sudo dpkg -i *deb
sudo apt --fix-broken install
# 色々足りないのでfixします
sudo apt install dkms
niccli
```
