# Atomカスタムメモ

AtomはReSTとMDのカスタムのために用いる。そのためのメモを記する。

## 事前準備

<http://pandoc.org/installing.html>

を入れる。WindowsならばMSIパッケージでOK。

macOSの場合、インストール後、"ATOM -> install shell..."で、apmが動くようにすること

## 初期設定

自分の場合は、

-   UI: One Dark
-   Syntax Theme Solarized Dark

## パッケージ

```
 apm install pandoc language-restructuredtext rst-preview-pandoc pretty-json file-icons japanese-menu markdown-scroll-sync markdown-writer tool-bar tool-bar-markdown-writer wordcount atom-beautify markdown-toc
 apm install atomic-emacs
 apm install remote-ftp
```

## 各種操作

### RESTのプレビュー

```
Ctl + Shift + E
```

### MDのプレビュー

```
Ctl + Shift + M
```

### JSONの整形

```
Ctl + Shift + P -> JSON::pretyfi
```

### 全体的に成果系

```
右クリックして"beautify editor contents"
```
