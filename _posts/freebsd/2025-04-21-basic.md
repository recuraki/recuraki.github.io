FreeBSDの基本的な調査
===

# 基本的な操作

## OSのupdate



```
  freebsd-update fetch
  > 出力されるファイルを確認
  freebsd-update install
   > 反映
  reboot
```

## ports treeのupdate

```
 portsnap fetch extract update
 2回目以降
  portsnap fetch update
```

# インストールメモ

## インストール(pkg)

```
 sudo pkg install lsof dmidecode pstree fping+ipv6 fping hping subversion rsync bash zsh sudo
 sudo pkg install nmap python screen ja_qkc vim emacs ja-nkf php5
 sudo pkg installt shark gcc
 sudo pkg install net-snmp ruby py-pip mercurial source-highlight
 # 以下は監視系の場合
 sudo pkg install munin-node apache22
 # 以下はシステム系の場合
 sudo pkg install mrtg rrdtool syslog-ng
 # 以下はクライアント系の場合
 sudo pkg install xorg fluxbox xfce4 aterm eterm
 sudo pkg install platex-japanese tex-dvipdfmx
```


## カーネルの再構築

まず、バックアップをとっておきます。

```
 sudo cp -rip /boot/kernel /boot/kernel.orig
 sudo cp -rip /usr/src /usr/src.orig

 cd /usr/src
 sudo make buildkernel
 sudo make installkernel
```
