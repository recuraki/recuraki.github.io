## TIPS

##### エイリアス問題


```
DocumentRoot /usr/home/kanai/public_html
```

として

```
<Directory /home/*/public_html>
  Order Allow,Deny
  Allow from all
```

パーミッションを与えても、/usr/homeにallowが与えられるだけで/homeには与えられない。

1. Directoryを/usr/homeでallowする
2. DocumentRoot /home/kanai/public_html

のいずれかとすることで許可出来る。

##### IPアドレス制限

特定のアドレスレンジから「のみ」の通信を受け付けるならば以下の通り

```
Order Deny,Allow
Deny from All
Allow from .hogetan.net
Allow from 10.0.0.0/8
```
