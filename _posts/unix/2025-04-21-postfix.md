## postfix

##### 特定のドメインだけ他のホストにリレーする
main.cfに


```
transport_maps = hash:/etc/postfix/transport
```

を追記する。次に、
transportに


```
special-domain.hogetan.net :[192.168.0.240]
```

のようにかき、

```
 postmap /etc/postfix/transport
 service postfix restart
 # 必要なら
 postqueue -f
```

##### メールの配送を一時的に止める


> postfix stop
 # すべてのメールをHOLDにする
> postsuper -h ALL
 # キューをみる
> mailq
 # <ID>のメールを削除
> postsuper -d <ID>
 # HOLDされているメールをみる
> postcat /var/spool/postfix/hold/<ID>
 # HOLDを解除(全部解除)
> postsuper -H ALL
> postfix start
