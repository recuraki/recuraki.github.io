## basic

```
virsh start node1
virsh list --all
virsh console node1
virsh reboot node1
```

## SnapShot

```
virsh snapshot-create-as node1 00-init
virsh snapshot-delete osctl1 02-checked
```

## ubuntu OpenStack nested kvm

VMwarePlayer

```
eth0: NAT
eth1: HostOnlyNetwork
```

```
apt-get install openssh-server
sudo vi /etc/network/interfaces
auto eth1
iface eth1 inet static
address 192.168.78.200
netmask 255.255.255.0
```

```
aptitude install vlan
sudo sed -i".orig" -e 's/\/\/us.archive.ubuntu.com/\/\/ftp.jaist.ac.jp/g'  /etc/apt/sources.list
sudo apt-get install kvm libvirt-bin bridge-utils virt-manager
sudo apt-get remove network-manager
```

```
brctl show
sudo virsh net-autostart default --disable

auto eth0
```
