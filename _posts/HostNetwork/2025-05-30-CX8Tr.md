ComputeX関連で[NVIDIA MMS4A20 800Gbps, DR4 Single-port OSFP, MPO](https://docs.nvidia.com/networking/display/9iat0mosfp800sprhs)の話が盛り上がっていたので情報の整理。

# 前提(電気の話)

- QSFP(QSFP28,56,112)は電気側が4lane
- OSFP(OSFP-RHS, QSFP-DD)は電気側が8lane(ペア)
- 2020年ごろまでの各電気側のSerdesは28Gである。
  - QSFP28として100G-LR4, 100G-SR4などが広く使われていた
- 2023年ごろから各電気のSerdesは112Gが出てきた
  - QSFPで400G時代
- 112GはSerdes的にBase56でPAM4すれば達成できる速度で比較的無理のない速度

# 前提(光側の話)
- 従来、SMF=1310nm, MMF=850nmと呼ばれていた。
- ところが100G-LR4, 100G-CWDM4くらいから急に状況が変化。
- 光側も高速で変調することが難しいので１波だけで200G, 400Gの情報が送れるような変調をかけることは難しい
- そこで、400Gを例にとれば100G分の変調 x 4本にすることにした。この後のアプローチが２つある。
- 4本を違う波長に変調して、1本に合波する。で光というのは色が違うと同じファイバを通れる（プリズム）。100G-LR4でいいなら1295.56/1300.05/1304.58/1309.14 nmに変調して、1本（正確にはTx/Rxで2本)に通す。
  - この場合、LC=既存のファイバを使える。ただし、変調ユニットが4種類必要になり、MuxDemuxが必要になる
- 4本を同じ波長にして、4本のファイバで通す。400G-DR4がこのイメージで1310/1310/1310/1310nmとして、MPO-12ケーブルのうち8芯=4本分をつかって伝送する。ただし、MPOコネクタが必要になり、中継区間の回線のファイバをたくさん使う。
- 4本を同じ波長(MPO)のメリットとしては、400G-DR4 - 100G-DRなどのブレイクアウト構成が取れること。

# ギアボックスの話
- ところがこれでは100G-DRなどで使われるQSFP28 100G-DRの説明がうまくつかない
- なぜなら、電気側25G x 4 -> 光 100G x 1波長をどのように実現しているのか？
- ギアボックスと呼ばれる装置を入れる。これにより25Gx4 -> 100GにうまくDSPで電気変調する
- それなら最初から電気側100G x 1でよいのでは？と思うかもしれないが、ギアボックスは`トランシーバの内部`で実装されるもの
- であるので、減衰などの許容が大きい。ホストから100G SERDESするのは大変

# さて、今回の話。800G

800Gのコンフィグレーションを考える。
- (112x8) SW-ASIC ---- (8pairの電気) ---- OSFP (112x8)   というのが通常考えられる組み合わせ
- ところがNVIDIAのプラットフォームでは、電気側224Gを使いたいらしい
- 冒頭のトランシーバのスペックを見るとぱっと見、MPO-12 x 1portなので、 400G-DR4っぽくみえる
が、そんなことはなくて、800G の MPO-12 x 1 port。ということは使っているのは8core = 4 pair
- SW-ASIC(112x8)  — (ギアボックス) — (224x4)この800GTrとなるのか？
- ところが、スペックを見る限り、 (ギアボックス) を入れておらず、SW-ASIC(224x4) —  (224x4)この800GTrになっていそう

ポイントは、OSFP800は8laneあるんだから、112 x 8でいいのに、なんでわざわざ224 x 4にしているの？そんなトランシーバ誰がつくるの？ 
と思うのだが...
